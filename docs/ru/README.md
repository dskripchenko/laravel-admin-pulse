# dskripchenko/laravel-admin-pulse

> 🌐 [English](../../README.md) · **Русский** · [Deutsch](../de/README.md) · [中文](../zh/README.md)

Лёгкая телеметрия для `dskripchenko/laravel-admin`: middleware `pulse` пишет время запросов в базу сэмплами (запросы к БД, задания и исключения записываются через сервис `Sampler`), а в админке появляются дашборд **«Телеметрия»**, индикатор доли ошибок в верхней панели и список **«Сэмплы телеметрии»**. Консольные команды сворачивают сэмплы в перцентили по окнам и удаляют устаревшие данные. Своя реализация без `laravel/pulse`.

Пакет-компаньон для [`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin).

## Установка

```bash
composer require dskripchenko/laravel-admin-pulse
php artisan migrate
```

Плагин регистрируется автоматически через Laravel package discovery. Публикация конфига:

```bash
php artisan vendor:publish --tag=admin-pulse-config
```

Поставьте агрегацию в планировщик — по ней строятся графики дашборда:

```php
Schedule::command('admin:pulse:aggregate')->everyFiveMinutes();
Schedule::command('admin:pulse:rotate')->daily();
```

## Дашборд «Телеметрия»

`/admin/dashboard/telemetry`, группа меню «Системные», для пользователей с правом `admin.system.pulse.view`. Собран из встроенных виджетов ядра, окно — последние 24 часа:

- **Плитки** — оценка числа запросов, доля ошибок 5xx, p95 времени ответа, число исключений.
- **Запросы в минуту** — запросы и ошибки 5xx (линейный график).
- **Время ответа** — p50 и p95 (линейный график).
- **Медленные маршруты** — маршрут, сэмплы, среднее, p95, максимум, 5xx.
- **Медленные запросы к БД** — отпечаток SQL, сэмплы, среднее, максимум.
- **Частые исключения** — исключение, сэмплы, когда было в последний раз.
- **Задания** — выполненные и упавшие по часам (столбцы с накоплением).

Индикатор в верхней панели становится предупреждением или ошибкой, когда доля ответов 5xx за последние 15 минут превышает пороги из конфига. Классы виджетов можно ставить и на свои дашборды. Подробности — в разделе [Использование](usage.md).
